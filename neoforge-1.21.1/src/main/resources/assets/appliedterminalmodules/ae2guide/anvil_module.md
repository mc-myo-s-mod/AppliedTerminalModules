# Anvil Module

<ItemImage id="appliedterminalmodules:anvil_module" scale={3} />

Install this card in a [Myotus terminal card slot](index.md) to use an anvil from the terminal.

## Anvil operations

Combine or repair items using normal anvil rules. Press **Rename** to edit the first item's name, then confirm or cancel to return to the terminal. The displayed level cost is paid when you take the result. Insufficient experience, incompatible enchantments and the survival level limit follow vanilla rules. The module has no anvil block to damage.

If you remove the module card or close the terminal, the remaining inputs are returned to your player inventory; items that do not fit are dropped.
