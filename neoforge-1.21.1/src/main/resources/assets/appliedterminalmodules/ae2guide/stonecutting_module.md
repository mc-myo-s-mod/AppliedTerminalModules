# Stonecutting Module

<ItemImage id="appliedterminalmodules:stonecutting_module" scale={3} />

Install this card in a [Myotus terminal card slot](index.md) to use a stonecutter from the terminal.

## Stonecutting

Place a valid input in the stonecutter and select the output you want. Available conversions follow the stonecutter recipes registered in the world. Take the output to complete the recipe.

Use the mouse wheel or page arrows to browse outputs. In JEI or EMI, **Alt + the recipe transfer button** targets the module. One set of ingredients is taken from ME storage, then your inventory, and the requested output is selected. The module must be installed and visible. The modifier key can be changed in Myotus settings.

If you remove the module card or close the terminal, the remaining input is returned to your player inventory; items that do not fit are dropped.
