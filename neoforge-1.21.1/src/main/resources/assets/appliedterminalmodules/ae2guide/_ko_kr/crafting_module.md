# 제작 모듈

<ItemImage id="appliedterminalmodules:crafting_module" scale={3} />

[Myotus 터미널 카드 슬롯](index.md)에 이 카드를 설치하면 터미널 옆에 **3×3 제작 그리드와 결과 슬롯**이 추가됩니다.

## 제작하기

그리드에 재료를 넣고 결과물을 꺼내 제작하세요. 결과 슬롯의 일반 클릭과 Shift 클릭은 터미널 메뉴 슬롯을 통해 처리됩니다. 서버가 제작법을 확인하고 결과물을 가져갈 때 재료를 소비합니다.

결과물은 한 번 제작한 묶음 전체를 가져옵니다. Shift 클릭은 한 묶음 전체가 인벤토리에 들어갈 때 한 번만 제작합니다. 여러 개가 나오는 결과를 버릴 때는 Ctrl+Q를 사용하세요. 일반 Q로 묶음을 나눌 수는 없습니다.

## JEI와 EMI 제작법 전송

JEI 또는 EMI에서 **3×3 안에 들어가는 일반적인 정형 또는 비정형 제작대 제작법**을 연 뒤 **+ / 채우기** 제작법 전송 버튼을 사용하면 설치된 제작 모듈의 그리드로 재료를 옮길 수 있습니다. 특수 제작법과 3×3보다 큰 제작법은 지원하지 않습니다. 전송은 서버가 검증합니다.

자체 제작창이 있는 터미널에서도 **Alt + 제작법 전송 버튼**으로 Myotus의 모듈 전송을 사용할 수 있습니다. 마지막으로 클릭한 호환 모듈이 우선됩니다. 조합 키는 Myotus 설정에서 바꿀 수 있습니다.

자체 제작창이나 패턴 인코딩 전송 기능이 있는 터미널은 기존 전송 버튼을 유지합니다. EMI에서는 제작법 화살표 위의 **제작 모듈 카드 +** 버튼으로 이 모듈을 지정해 채울 수 있습니다. JEI에서는 더 우선하는 제작법별 전송 기능이 없을 때 AE2 터미널 메뉴에서 이 모듈을 사용합니다. 외부 애드온의 터미널 메뉴는 별도 등록이 필요합니다.

요청 한 번에 **제작법 한 세트**를 채웁니다. 재료는 **ME 저장소를 먼저** 확인한 뒤 **플레이어의 주 인벤토리와 핫바**에서 가져옵니다. 열린 터미널 때문에 잠긴 플레이어 인벤토리 슬롯은 사용하지 않습니다.

그리드의 올바른 위치에 이미 있는 재료는 유지됩니다. 제작법을 방해하는 아이템은 ME 저장소에 먼저 반환하고, 이어서 플레이어 인벤토리에 반환합니다. 반환할 공간이 없으면 해당 아이템은 그리드에 남습니다. 재료가 부족하면 그리드가 일부만 채워질 수 있습니다.

모듈의 결과 슬롯에서 결과물을 가져가면 제작이 완료됩니다. 전송 기능은 부족한 재료의 자동 제작 요청, 그리드의 지속적인 재충전, 최대 수량 전송을 지원하지 않습니다.

## 카드 제거와 터미널 닫기

제작 그리드는 현재 열려 있는 플레이어의 터미널 메뉴에 속합니다. 재료는 카드에 저장되지 않으며, 같은 터미널을 보는 다른 플레이어의 그리드와도 공유되지 않습니다.

제작 모듈 카드를 제거하거나 터미널을 닫으면 그리드에 남은 재료가 플레이어 인벤토리로 반환됩니다. 인벤토리에 들어가지 못한 아이템은 떨어집니다. 그리드를 비울 때 결과 미리보기가 실제 제작된 아이템으로 지급되지는 않습니다.

## 제작법

AE2 기본 카드와 제작대를 사용하는 조합 순서가 없는 제작법입니다.
